# FreeLaneLab
FreeLaneLab is an Android App that makes building roads in Freeways easier than ever. Just drag markers to the desired positions on the screen, and let the app do the rest.

<img src="https://www.alexin.de/projects/freelanelabs/github/showreel1.png" width="500">

### Features
* Uses SystemAlertWindow to display an easy to use Overlay on top of other apps
* Draws perfectly smooth roads through the Accessibility API
* Points snap into place when dragged in a straight line next to another one
* Overlay can be collapsed to take up minimal screen space

### Tools
* Line: Draws a straight line from point A to point B
* Curve: Calculates the circle passing through points A, B and C, then draws a curve between point A and C
* Circle: Draws the Circle defined by points A, B and C
